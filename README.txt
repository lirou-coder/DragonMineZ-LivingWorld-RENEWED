DRAGON MINE Z: LIVING WORLD 2.2.0 — FINAL PUBLIC RELEASE
=========================================================

Living World adds persistent Dragon Mine Z fighters who grow, remember, form relationships,
join factions, use real equipment/techniques, follow daily lives, and take part in world activity.

FINAL 2.2.0 HIGHLIGHTS
- Persistent Living World fighters with relationships, equipment, techniques, histories and goals.
- Daily schedules and visible activities, including training, rest, travel and social/world behavior.
- DMZ-native combat, Ki, flight, transformations and weapon use with bounded NPC progression.
- Factions, People journal, companion travel, sanctioned sparring, supply requests and Patrol requests.
- Scientist gameplay with persistent Scientist-created Saibamen specimens and potency information.
- World Menaces / Red Ribbon Experiment content and persistent world continuity.
- Integrated Meditation, including configurable breakthroughs, shared meditation and form practice.
- Extensive GUI/settings controls, including NPC growth, Ki safety and Minecraft-mob engagement.

COMPATIBILITY TARGET
- Minecraft 1.20.1
- Forge 47.4.10
- Dragon Mine Z 2.1.3
- GeckoLib 4.8.4
- Java 17
- Normal Dragon Mine Z runtime dependencies (Curios / TerraBlender as required by DMZ)

UPGRADING
Living World 2.2.0 is designed to load worlds from the two previously published CurseForge lines,
1.0.0 and 1.9.0. See UPGRADE_TO_2.2.0.txt and COMPATIBILITY_AND_SAVE_SAFETY_2.2.0.txt.
Back up an important world before any mod update.

IMPORTANT
Do not install the old standalone DragonMineZ-Meditation / dbzmeditation JAR. Meditation is
integrated into Living World.

BUILDING FROM SOURCE
Run BUILD_LIVING_WORLD_JAR.bat on Windows with Java 17. The final files are written to RELEASE/.
See HOW_TO_BUILD.txt and SOURCE_AND_LICENSE.txt.
